## rnic.io

A definitive, datasheet-depth guide to RDMA-capable NIC architecture. Every mechanism a real RNIC needs -- Queue Pair management, memory registration, the RoCEv2 wire format, the TX/RX pipelines, reliability and congestion control -- opened into a pipeline stage, a state machine, a caching structure, and a failure mode, not left as a black box.

Concrete throughout: this book writes RoCEv2 specifically, not a protocol-agnostic hedge. Written by [Aditya Shevade](/about), a working DV engineer -- see [chipdv.io](https://chipdv.io) for the verification-side companion series.
